# CCAE - California Center For The Performing Arts, Escondido

This is the California Center For The Performing Arts, Escondido site platform under Open Coding Society.

## Features
- An organized and streamlined website
- More to come (WIP)

## GitHub Pages Setup
- Go to Settings --> Page --> Build and activate GitHub Actions under the Deployments (not Deploy from branch)
- Update/Confirm _config.yml to reflect baseurl

## Contributions

Contributions are welcome from students, teachers, evaluators and collaborators.

To contribute:
- Create a fork/branch of the main repository
- Make clear, scoped updates
- Open a pull request with context explaining changes for reviewers
